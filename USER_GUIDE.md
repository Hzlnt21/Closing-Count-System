# Panduan Pengguna

## Instalasi pertama

1. Unduh file APK dari halaman **Releases** repository ini.
2. Buka APK pada HP Android. Jika diminta, izinkan pemasangan aplikasi dari sumber tersebut.
3. Pilih **Install**, lalu buka **Closing Count System**.

Aplikasi berjalan sepenuhnya offline dan tidak memerlukan akun.

## Alur penggunaan

1. Buka **Bahan** untuk memeriksa kategori dan bahan baku.
2. Buka **Menu** untuk membuat kategori menu, menu, dan memilih bahan yang digunakan.
3. Buka **Closing**, pilih tanggal, lalu isi jumlah setiap menu yang terjual.
4. Periksa hasil **Terjual/Out** per kategori bahan, kemudian simpan closing.
5. Buka **Riwayat** untuk melihat, mengedit, atau mengekspor closing ke Excel.

Satu bahan pada resep dihitung satu kali untuk setiap satu menu yang terjual.

## Backup

1. Dari halaman utama, buka **Backup & Restore**.
2. Pilih **Buat backup**.
3. Tentukan nama dan lokasi file JSON, lalu simpan.
4. Salin file tersebut ke tempat aman di luar HP bila diperlukan.

Backup mencakup kategori, bahan, menu, resep, dan seluruh riwayat closing.

## Restore

1. Buka **Backup & Restore** lalu pilih **Restore backup**.
2. Pilih file JSON backup yang valid.
3. Baca konfirmasi dengan teliti, lalu lanjutkan restore.

Restore mengganti data aktif dengan isi backup. Buat backup terbaru sebelum restore jika data aktif masih diperlukan.

## Update aplikasi

1. Buat backup terlebih dahulu sebagai tindakan pengamanan.
2. Unduh APK versi terbaru dari halaman **Releases** yang sama.
3. Buka APK dan pilih **Update**.

Jangan uninstall aplikasi sebelum update karena uninstall akan menghapus data lokal. Android hanya dapat melakukan update jika package ID dan signing key APK sama dengan versi yang sudah terpasang.

## Memindahkan data ke HP lain

1. Buat backup pada HP lama.
2. Pasang aplikasi pada HP baru.
3. Pindahkan file JSON backup ke HP baru.
4. Gunakan **Restore backup** pada HP baru.

## Privasi

Semua data disimpan pada perangkat. File hanya keluar dari aplikasi saat pengguna memilih ekspor Excel atau membuat backup.
