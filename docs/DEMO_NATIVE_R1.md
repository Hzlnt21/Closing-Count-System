and17 warnings. The9 normal native invocations use the latest test APK. Core
service suites are inherited from their documented checkpoints; they were not
rerun for this test/document-only change.

launcher. R2's stale IME-view check timed out at login. R3 passed Rani but Dimas's
process exited before class start; its reason is unconfirmed. R4 confirmed4/6

retained separately in the global program evidence and are excluded from the
R5 pass count. The driver now uses file-backed launcher logs, sequential
secondary users, stable actual IME checks and correct dialog-button interaction.

Archived drivers use the developer's explicit Windows workspace/QA environment;
they are separate from the [portable operator payload](DEMO_PORTABILITY_R1.md).
