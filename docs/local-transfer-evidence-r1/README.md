# Local transfer evidence R1

engine, legacy, phone-light and phone-dark-large are final same-APK evidence. The before-picker-nav-fix directory is a failed/superseded run. Its log records a system-preview click target error, and its home image demonstrates the old clipped labels. Do not count it as final acceptance.

Native fixtures use only dummy content. Each native run restores the original app-local snapshot and compares online table digests. Exported JSON files remain available for independent comparison. The picker PNG is captured immediately on opening, before its list loads; the instrumentation then selects an actual filename and completes the flow.

The harness archives scripts for the owned D:/Code QA lab and named emulator, not a portable public demo installer. No APKs or secrets are included. See ../LOCAL_TRANSFER_UI_R1.md for exact scope and remaining work.
